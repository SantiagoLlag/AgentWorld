# AgentWorld — AI Agent Use-Case Atlas

A research atlas of **what AI agents are used for and how each kind is built**: architecture, frameworks, tools, memory, evaluation, failure modes, and a recipe for building each one yourself. Researched on 2026-10-01 by a 12-agent research workflow; every claim about a named company is tagged **[Documented]** (with a source) or **[Inferred]**.

## How to read it

| Order | File | What it gives you |
|---|---|---|
| 1 | [`research/02-learning-path.md`](research/02-learning-path.md) | 8-level hands-on curriculum (L1 augmented LLM → L8 production ops). Each level has a project, acceptance criteria and an eval to pass, and links the dossier sections to read. **Start here.** |

## Full use-case inventory (103 found → mapped to an archetype)

The two discovery agents found 103 distinct use cases (plus one entry of adoption reports, left out here). Each one is mapped to the dossier whose architecture it shares, so for any use case you know which architecture to study.
**Teardown** = at least one of its exemplars is analysed by name in that dossier. **Pattern only** = the dossier covers the architecture, but these specific exemplars are not torn down; this applies mostly to industry-specific cases (healthcare, insurance, procurement, real estate, energy…).

## Method and limits

- **Pipeline (12 agents):** 2 discovery agents (industries + business functions; technical types + published deployments) and 1 frameworks-landscape agent → 1 taxonomy agent → 6 deep-dive agents (2 dossiers each, each followed by a self-check of 5+ key claims) → 2 synthesis agents.
